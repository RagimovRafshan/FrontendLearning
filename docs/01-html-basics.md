# Модуль 1: Основы HTML5

## 📖 Теория

### Что такое HTML?
HTML (HyperText Markup Language) — это язык разметки, который определяет структуру и содержание веб-страницы.

### Семантическая верстка
Семантические теги помогают понять смысл содержимого как браузерам, так и разработчикам:

```html
<!-- Плохо -->
<div class="header">...</div>
<div class="nav">...</div>
<div class="main">...</div>

<!-- Хорошо -->
<header>...</header>
<nav>...</nav>
<main>...</main>
```

### Основные семантические теги:
- `<header>` - шапка сайта/раздела
- `<nav>` - навигация
- `<main>` - основное содержимое
- `<article>` - независимый контент (статья, пост)
- `<section>` - тематическая группа контента
- `<aside>` - боковая панель, дополнительный контент
- `<footer>` - подвал сайта/раздела
- `<figure>` и `<figcaption>` - изображения с подписями
- `<time>` - дата и время
- `<mark>` - выделенный текст

### Структура HTML-документа

```html
<!DOCTYPE html>
<html lang="ru">
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <meta name="description" content="Описание страницы для SEO">
    <title>Заголовок страницы</title>
    <link rel="stylesheet" href="styles.css">
</head>
<body>
    <header>
        <nav>
            <!-- Навигация -->
        </nav>
    </header>
    
    <main>
        <h1>Основной заголовок</h1>
        <section>
            <h2>Подзаголовок раздела</h2>
            <p>Текст параграфа</p>
        </section>
    </main>
    
    <footer>
        <p>&copy; 2024 Моя компания</p>
    </footer>
</body>
</html>
```

### Иерархия заголовков
- `<h1>` - главный заголовок (один на страницу!)
- `<h2>` - заголовки разделов
- `<h3>` - подразделы
- и так далее до `<h6>`

### Работа с формами

```html
<form action="/submit" method="POST">
    <label for="email">Email:</label>
    <input 
        type="email" 
        id="email" 
        name="email" 
        required 
        placeholder="example@mail.com"
    >
    
    <label for="password">Пароль:</label>
    <input 
        type="password" 
        id="password" 
        name="password"
        minlength="8"
        required
    >
    
    <label for="message">Сообщение:</label>
    <textarea id="message" name="message" rows="5"></textarea>
    
    <button type="submit">Отправить</button>
</form>
```

### Доступность (a11y)
- Используйте семантические теги
- Добавляйте `alt` к изображениям
- Используйте `aria-*` атрибуты при необходимости
- Обеспечьте навигацию с клавиатуры
- Проверяйте контрастность цветов
