# FrontendLearning

План обучения для Middle Frontend разработчика (с нуля до продвинутого уровня).

## 📚 Структура обучения

### 1. **HTML & CSS** (`src/html-css/`)
- Основы HTML5, семантика
- CSS: селекторы, каскад, специфичность
- Flexbox и Grid
- Адаптивный дизайн, медиа-запросы
- CSS-переменные, методологии (BEM)
- Современные возможности CSS

### 2. **JavaScript Core** (`src/js-core/`)
- Основы синтаксиса, типы данных
- Функции, замыкания, область видимости
- Асинхронность: Promise, async/await
- DOM манипуляции, события
- ES6+ фичи
- Работа с объектами, массивами
- Прототипы, классы
- Модули, импорты/экспорты

### 3. **TypeScript** (`src/typescript/`)
- Базовые типы
- Интерфейсы, дженерики
- Utility типы
- Типизация функций, классов
- Продвинутые паттерны типизации

### 4. **React** (`src/react/`)
- Компоненты, props, state
- Хуки (useState, useEffect, custom hooks)
- Контекст, редьюсеры
- Оптимизация производительности
- Паттерны проектирования

### 5. **Инструменты и практики** (`docs/`)
- Сборщики (Vite, Webpack)
- Тестирование (Jest, Testing Library)
- Линтинг, форматирование
- Git, работа в команде
- Производительность, доступность

---

## 🚀 Как использовать

Каждый модуль содержит:
- Теоретические материалы
- Примеры кода
- Практические задания
- Проверочные вопросы

Начните с первого модуля и двигайтесь последовательно!
