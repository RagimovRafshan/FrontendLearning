# FrontendLearning: Путь от новичка до Middle Frontend разработчика

Полный план обучения с **нулевого уровня** до **Middle Frontend разработчика**.
Программа рассчитана на 6-12 месяцев интенсивного обучения с практикой.

---

## 📋 Этапы обучения

### **Этап 1: Фундамент (1-2 месяца)**
#### Основы веб-разработки
- **HTML5**: семантика, структура документа, формы, доступность (a11y)
- **CSS3**: селекторы, каскад, специфичность, наследование
- **Базовая вёрстка**: блочная модель, позиционирование, дисплей

#### Практика:
- Вёрстка простых страниц (лендинг, форма регистрации)
- Работа с DevTools браузера

---

### **Этап 2: Продвинутый CSS (1 месяц)**
- **Flexbox** и **Grid** — современные макеты
- **Адаптивный дизайн**: медиа-запросы, мобильный первый подход
- **CSS-переменные** и кастомные свойства
- **Методологии**: BEM, SMACSS
- **Препроцессоры**: SASS/SCSS (опционально)
- **Анимации**: transitions, keyframes, transform

#### Практика:
- Адаптивный лендинг с анимациями
- Компонентная библиотека стилей

---

### **Этап 3: JavaScript с нуля (2-3 месяца)**
#### Базовый уровень:
- Синтаксис, переменные, типы данных
- Операторы, условия, циклы
- Функции (обычные, стрелочные)
- Массивы и методы массивов
- Объекты, деструктуризация

#### Средний уровень:
- Область видимости, замыкания
- Прототипы, классы, наследование
- Модули (import/export)
- Работа с DOM
- События, обработчики событий

#### Продвинутый уровень:
- **Асинхронность**: Callbacks, Promises, async/await
- Fetch API, работа с сервером
- Ошибки, try/catch
- ES6+ фичи (spread, rest, optional chaining)
- Регулярные выражения
- LocalStorage, sessionStorage

#### Практика:
- Интерактивные компоненты (слайдер, модальные окна)
- Приложение с fetch запросами (погода, список задач)
- Мини-игра на чистом JS

---

### **Этап 4: TypeScript (1 месяц)**
- Зачем нужен TypeScript
- Базовые типы (string, number, boolean, array, tuple)
- Интерфейсы и типы
- Дженерики (Generics)
- Utility типы (Partial, Pick, Omit, Record)
- Типизация функций и классов
- Типизация асинхронного кода

#### Практика:
- Рефакторинг JS-кода на TypeScript
- Типизация API ответов

---

### **Этап 5: Инструменты разработчика (2 недели)**
- **Git**: базовые команды, ветки, мерджи, pull requests
- **NPM/Yarn/PNPM**: управление пакетами
- **Сборщики**: Vite (современный), Webpack (базовое понимание)
- **Линтеры**: ESLint, Prettier
- **DevTools**: отладка, профилирование

---

### **Этап 6: React — основной фреймворк (2-3 месяца)**
#### Основы React:
- JSX синтаксис
- Компоненты (функциональные)
- Props и State
- Рендеринг списков, ключи
- Обработка событий

#### Хуки (Hooks):
- useState, useEffect
- useContext, useReducer
- Custom hooks
- useMemo, useCallback (оптимизация)

#### Продвинутый React:
- Context API для глобального состояния
- Паттерны: Compound Components, Render Props, HOC
- Оптимизация производительности (React.memo, lazy loading)
- Error Boundaries
- Работа с формами (controlled/uncontrolled)

#### Экосистема React:
- **React Router** — навигация и роутинг
- **State Management**: Redux Toolkit / Zustand / MobX
- **Библиотеки компонентов**: Material UI, Ant Design, Chakra UI (на выбор)

#### Практика:
- SPA приложение (интернет-магазин, блог, дашборд)
- Приложение с авторизацией и роутингом
- Интеграция с реальным API

---

### **Этап 7: Next.js — SSR/SSG фреймворк (1 месяц)**
- Отличия от обычного React
- Роутинг в Next.js (App Router / Pages Router)
- Server Components vs Client Components
- Data fetching (getStaticProps, getServerSideProps)
- API Routes
- SEO оптимизация
- Deployment (Vercel)

#### Практика:
- Полноценный блог или интернет-магазин с SSR

---

### **Этап 8: Тестирование (3-4 недели)**
- **Unit тесты**: Jest, Vitest
- **Component тесты**: React Testing Library
- **E2E тесты**: Cypress или Playwright
- TDD подход (базовое понимание)

#### Практика:
- Покрытие тестами существующего проекта

---

### **Этап 9: Дополнительные фреймворки (опционально, 1 месяц)**
Для расширения кругозора:
- **Vue 3** (Composition API) — альтернатива React
- Или **Angular** — корпоративный стандарт

---

### **Этап 10: Профессиональные навыки (постоянно)**
- **Веб-производительность**: Lighthouse, Core Web Vitals, оптимизация
- **Доступность (a11y)**: WCAG, ARIA атрибуты
- **Безопасность**: XSS, CSRF, CORS
- **PWA**: Service Workers, офлайн режим
- **GraphQL** (опционально): Apollo Client, URQL
- **WebSockets**: реальное время
- **Docker** (базово): контейнеризация приложений

---

## 🎯 Критерии Middle Frontend разработчика

После прохождения программы ты должен уметь:

✅ **Технические навыки:**
- Самостоятельно разрабатывать сложные SPA приложения
- Работать с TypeScript на продвинутом уровне
- Настраивать сборку проекта (Vite/Webpack)
- Писать тесты (unit, integration, e2e)
- Оптимизировать производительность
- Работать в команде с Git

✅ **Архитектурные навыки:**
- Выбирать правильные паттерны для задач
- Проектировать компонентную архитектуру
- Управлять состоянием приложения
- Декомпозировать задачи

✅ **Софт скиллы:**
- Читать и понимать чужой код
- Проводить code review
- Оценивать сроки задач
- Коммуницировать с дизайнерами и backend-разработчиками

## 🚀 Как начать

1. Начни с **Этапа 1** (HTML & CSS основы)
2. Выполняй практические задания после каждой темы
3. Не переходи к следующему этапу, пока не усвоил предыдущий
4. Создавай портфолио из выполненных проектов
5. Задавай вопросы по каждому модулю

**Важно:** Обучение должно быть с балансом теории (30%) и практики (70%).
