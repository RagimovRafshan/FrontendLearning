# Модуль 1: Основы React

## 📚 Теория

### 1.1 Что такое React?
React - это библиотека для построения пользовательских интерфейсов на основе компонентов.

**Ключевые концепции:**
- **Компоненты** - строительные блоки UI
- **JSX** - синтаксическое расширение для описания UI
- **Virtual DOM** - оптимизация рендеринга
- **Однонаправленный поток данных** - данные текут сверху вниз

### 1.2 Создание компонентов

```jsx
// Функциональный компонент
function Welcome({ name }) {
  return <h1>Привет, {name}!</h1>;
}

// Экспорт компонента
export default Welcome;
```

### 1.3 JSX синтаксис

```jsx
// Переменные в JSX
const name = "Алексей";
const element = <h1>Привет, {name}</h1>;

// Условия
function Greeting({ isLoggedIn }) {
  return isLoggedIn ? <button>Выйти</button> : <button>Войти</button>;
}

// Списки
function UserList({ users }) {
  return (
    <ul>
      {users.map((user, index) => (
        <li key={user.id}>{user.name}</li>
      ))}
    </ul>
  );
}
```

### 1.4 Props (свойства)

```jsx
// Родительский компонент
function App() {
  return <Welcome name="Анна" age={25} />;
}

// Дочерний компонент
function Welcome({ name, age }) {
  return (
    <div>
      <h2>{name}</h2>
      <p>Возраст: {age}</p>
    </div>
  );
}
```

### 1.5 State (состояние)

```jsx
import { useState } from 'react';

function Counter() {
  // Объявление состояния
  const [count, setCount] = useState(0);

  return (
    <div>
      <p>Счетчик: {count}</p>
      <button onClick={() => setCount(count + 1)}>
        Увеличить
      </button>
    </div>
  );
}
```

### 1.6 Обработка событий

```jsx
function Form() {
  const handleSubmit = (event) => {
    event.preventDefault();
    console.log('Форма отправлена');
  };

  const handleChange = (event) => {
    console.log(event.target.value);
  };

  return (
    <form onSubmit={handleSubmit}>
      <input onChange={handleChange} placeholder="Введите текст" />
      <button type="submit">Отправить</button>
    </form>
  );
}
```

### 1.7 Жизненный цикл компонента

```jsx
import { useEffect } from 'react';

function UserProfile({ userId }) {
  useEffect(() => {
    // Выполняется после монтирования
    console.log('Компонент смонтирован');

    // Очистка при размонтировании
    return () => {
      console.log('Компонент размонтирован');
    };
  }, [userId]); // Зависимости

  return <div>Профиль пользователя</div>;
}
```

## 🎯 Практические задания

### Задание 1: Базовый компонент (Уровень: Начинающий)
Создайте компонент `Card`, который принимает пропсы:
- `title` (строка)
- `description` (строка)
- `imageUrl` (строка, опционально)

Компонент должен отображать карточку с заголовком, описанием и изображением (если передано).

**Требования:**
- Используйте деструктуризацию пропсов
- Добавьте проверку на наличие изображения
- Экспортируйте компонент как default

### Задание 2: Список задач (Уровень: Средний)
Создайте компонент `TodoList`, который:
- Принимает массив задач через пропс `todos`
- Каждая задача имеет структуру: `{ id: number, text: string, completed: boolean }`
- Отображает список задач с чекбоксами
- При клике на чекбокс задача помечается как выполненная/невыполненная

**Требования:**
- Используйте ключи для списков
- Реализуйте обработку клика
- Стилизируйте выполненные задачи (зачеркнутый текст)

### Задание 3: Интерактивный счетчик (Уровень: Средний)
Создайте компонент `Counter` с функционалом:
- Отображение текущего значения счетчика
- Кнопки "+", "-", "Сброс"
- Минимальное значение: 0
- Изменение цвета текста при значении > 10

**Требования:**
- Используйте хук `useState`
- Реализуйте логику ограничения минимального значения
- Добавьте условное форматирование

### Задание 4: Форма регистрации (Уровень: Продвинутый)
Создайте компонент `RegistrationForm` с полями:
- Имя (обязательное, мин. 2 символа)
- Email (обязательное, валидация формата)
- Пароль (обязательное, мин. 6 символов)
- Подтверждение пароля (должно совпадать)

**Требования:**
- Контролируемые компоненты
- Валидация в реальном времени
- Отображение ошибок под каждым полем
- Блокировка кнопки отправки при невалидных данных
- Обработка отправки формы (вывод данных в консоль)

### Задание 5: Галерея изображений (Уровень: Продвинутый)
Создайте компонент `ImageGallery`:
- Принимает массив изображений `{ id, url, title }`
- Отображает сетку миниатюр
- При клике на миниатюру открывается модальное окно с большим изображением
- Кнопки "Назад"/"Вперед" для навигации
- Закрытие по клику вне изображения или по Esc

**Требования:**
- Управление состоянием модального окна
- Навигация между изображениями
- Обработка клавиатуры (Esc)
- Анимация появления (опционально)
