# 🏗 ООП и Функциональное программирование

## Теория

### Классы

```javascript
class Person {
    constructor(name) {
        this.name = name;
    }
    
    greet() {
        return `Hello, ${this.name}`;
    }
}
```

### FP методы массивов

```javascript
array.map(x => x * 2);
array.filter(x => x > 0);
array.reduce((acc, x) => acc + x, 0);
```
