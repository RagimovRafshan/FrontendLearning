# 🎓 Путь от новичка до Middle Frontend разработчика

Добро пожаловать в полный курс обучения Frontend-разработке! Этот курс проведет тебя от абсолютного нуля до уровня Middle разработчика.

## 📋 Структура обучения

Курс разделен на 8 основных этапов. Каждый этап содержит подтемы с теорией, практическими заданиями и проверочными вопросами.

### Этап 1: HTML & CSS (4-6 недель)
**Цель:** Научиться создавать семантически правильные, адаптивные и красивые веб-страницы.

- **01-html-basics** — Основы HTML5, семантика, формы, таблицы
- **02-css-fundamentals** — Селекторы, цвета, шрифты, блочная модель
- **03-layouts-flex-grid** — Flexbox и CSS Grid для сложных макетов
- **04-responsive-design** — Адаптивность, медиа-запросы, мобильный первый подход
- **05-advanced-css** — Анимации, трансформации, CSS-переменные, методология BEM
- **06-project** — Финальный проект: лендинг или блог

### Этап 2: JavaScript с нуля (8-10 недель)
**Цель:** Полное понимание языка JavaScript, от основ до продвинутых концепций.

- **01-js-basics** — Переменные, типы данных, операторы, условия, циклы
- **02-functions-scope** — Функции, область видимости, замыкания
- **03-dom-events** — Работа с DOM, события, манипуляции с элементами
- **04-asynchronous-js** — Callbacks, Promises, async/await, AJAX, Fetch API
- **05-es6-plus** — Стрелочные функции, деструктуризация, spread/rest, модули
- **06-oop-functional** — ООП, функциональное программирование, паттерны
- **07-project** — Финальный проект: интерактивное веб-приложение

### Этап 3: TypeScript (3-4 недели)
**Цель:** Освоить статическую типизацию и писать надежный код.

- **01-ts-basics** — Основы типов, интерфейсы, базовые конструкции
- **02-interfaces-generics** — Продвинутые интерфейсы, дженерики, утилиты типов
- **03-advanced-types** — Union types, type guards, conditional types
- **04-react-with-ts** — Типизация React компонентов, хуков, пропсов
- **05-project** — Финальный проект: типизированное приложение

### Этап 4: Инструменты (2-3 недели)
**Цель:** Освоить профессиональные инструменты разработки.

- **01-git-github** — Git основы, ветвление, merge, rebase, GitHub flow
- **02-npm-yarn** — Менеджеры пакетов, package.json, скрипты
- **03-webpack-vite** — Сборщики проектов, конфигурация, оптимизация
- **04-eslint-prettier** — Линтинг, форматирование, стандарты кода
- **05-debugging** — Отладка в браузере и редакторе, source maps

### Этап 5: React + экосистема (8-10 недель)
**Цель:** Стать уверенным React-разработчиком.

- **01-react-basics** — JSX, компоненты, props, state, жизненный цикл
- **02-hooks-deep** — Все хуки, кастомные хуки, лучшие практики
- **03-state-management** — Context API, Redux Toolkit, Zustand
- **04-routing** — React Router v6, навигация, защищенные роуты
- **05-performance** — Оптимизация рендеринга, memo, useMemo, useCallback
- **06-testing-react** — Тестирование компонентов, хуков, интеграционные тесты
- **07-project** — Финальный проект: полноценное SPA приложение

### Этап 6: Next.js (4-5 недель)
**Цель:** Освоить серверный рендеринг и современные подходы к построению приложений.

- **01-nextjs-basics** — Введение, файловая маршрутизация, SSR/SSG
- **02-data-fetching** — getStaticProps, getServerSideProps, ISR
- **03-api-routes** — Создание API внутри Next.js
- **04-authentication** — Аутентификация, авторизация, JWT
- **05-deployment** — Деплой на Vercel, оптимизация, мониторинг
- **06-project** — Финальный проект: полнофункциональное приложение

### Этап 7: Тестирование (3-4 недели)
**Цель:** Научиться писать надежные тесты и следовать TDD.

- **01-unit-testing** — Unit тесты с Jest/Vitest
- **02-integration-testing** — Интеграционные тесты компонентов
- **03-e2e-testing** — End-to-end тесты с Cypress/Playwright
- **04-mocking** — Моки, стабы, шпионы
- **05-tdd** — Test Driven Development, лучшие практики

### Этап 8: Дополнительно (4-6 недель)
**Цель:** Расширить кругозор и освоить профессиональные навыки.

- **01-vue3-basics** — Основы Vue 3, Composition API
- **02-angular-intro** — Введение в Angular, сравнение подходов
- **03-professional-skills** — Code review, работа в команде, оценка задач
- **04-system-design** — Архитектура фронтенд приложений, паттерны

---

## 🎯 Как проходить обучение

1. **Последовательно** — Проходите этапы по порядку, не перескакивая
2. **Теория + Практика** — Изучайте теорию и сразу применяйте на практике
3. **Проекты** — Выполняйте финальные проекты каждого этапа
4. **Вопросы** — Отвечайте на проверочные вопросы для самопроверки
5. **Повторение** — Возвращайтесь к сложным темам при необходимости

## ✅ Критерии уровня Middle

После завершения курса вы сможете:

- Самостоятельно разрабатывать сложные фронтенд приложения
- Писать чистый, поддерживаемый и типизированный код
- Настраивать сборку и оптимизировать производительность
- Покрывать код тестами и следовать лучшим практикам
- Работать в команде, проводить code review
- Проектировать архитектуру компонентов и приложений
