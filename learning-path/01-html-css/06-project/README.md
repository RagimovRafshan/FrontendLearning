# 🏆 Финальный проект этапа HTML/CSS

## Задание: Создать полноценный лендинг или блог

### Требования к проекту

#### 1. Структура (HTML)
- [ ] Семантическая верстка (header, nav, main, section, article, aside, footer)
- [ ] Правильная иерархия заголовков (h1 → h2 → h3)
- [ ] Формы с label и валидацией
- [ ] Адаптивные изображения с alt
- [ ] Валидный HTML (проверка на W3C Validator)

#### 2. Стилизация (CSS)
- [ ] CSS переменные для темизации
- [ ] Методология BEM для именования классов
- [ ] Flexbox для компонентов
- [ ] CSS Grid для макета
- [ ] Адаптивность (Mobile First)
- [ ] Медиа-запросы для всех breakpoints
- [ ] Hover и focus состояния
- [ ] Плавные переходы (transitions)
- [ ] Анимации при необходимости

#### 3. Страницы/Секции

**Вариант A: Лендинг компании**
- Hero секция с CTA
- О нас (преимущества)
- Услуги/Продукты (карточки)
- Отзывы
- Команда
- Контакты (форма)
- Footer

**Вариант B: Персональный блог**
- Header с навигацией
- Hero секция с информацией об авторе
- Список статей (карточки)
- Страница статьи
- Боковая панель (категории, теги)
- Форма подписки
- Footer

**Вариант C: Интернет-магазин (упрощенный)**
- Header с корзиной
- Каталог товаров (сетка)
- Карточка товара
- Фильтры/Сортировка
- Страница товара
- Корзина
- Checkout форма

#### 4. Технические требования
- [ ] Кроссбраузерность (Chrome, Firefox, Safari, Edge)
- [ ] Адаптивность (320px - 1920px+)
- [ ] Производительность (Lighthouse score > 90)
- [ ] Доступность (a11y)
- [ ] Чистый код без дублирования

## 🎯 Критерии оценки

| Критерий | Вес | Описание |
|----------|-----|----------|
| Семантика HTML | 15% | Правильное использование тегов |
| Адаптивность | 25% | Корректное отображение на всех экранах |
| CSS архитектура | 20% | BEM, переменные, организация кода |
| Визуальное качество | 20% | Соответствие дизайну, аккуратность |
| Производительность | 10% | Скорость загрузки, оптимизация |
| Доступность | 10% | A11y стандарты |
